# Есть мысли?

Mindex — персональный AI-ассистент для планирования задач в локальном браузере.

## Локальный запуск

1. Установи зависимости:

```bash
npm install
```

2. Создай файл `.env` на основе `.env.example` и заполни ключ Groq:

```bash
GROQ_API_KEY=
```

3. Запусти dev-сервер:

```bash
npm run dev
```

4. Открой приложение в браузере:

```bash
http://localhost:3000
```

Если нужен запуск собранной версии, используй:

```bash
npm run build
npm run preview
```
