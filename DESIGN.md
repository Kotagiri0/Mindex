## ⚠️ Шрифты — нужна помощь

| Шрифт | Статус | Где используется |
|-------|--------|-----------------|
| Muller Regular | ✅ в проекте | Основной текст, навигация |
| Muller Medium | ✅ в проекте | Названия задач, заголовки секций |
| Random Grotesque Spacious Book | ✅ в проекте | "есть мысли?", "ПЯТНИЦА", "апрель", "настройки" |
| Russisch Sans SemiBold | ❌ **ОТСУТСТВУЕТ** | Дни недели в календаре (пн, вт, ...) |

**→ Нужен файл шрифта Russisch Sans SemiBold** (`.ttf` / `.woff2`). Без него дни недели будут в Muller — это видимый костыль.

## Компоненты

### Сайдбар — развёрнутый (190px)

```
┌────────────────────┐
│ [Лого]      [□]   │  ← лого 35px + кнопка свернуть
├────────────────────┤
│  + Новый чат      │
│  ☀ Сегодня        │
│  □ Календарь      │  ← активный = чёрный pill
│  ○ Твои мысли     │
├────────────────────┤
│  Заметки      ∨   │  ← секция, коллапсируемая
│  Разбор созвона...│
│  Ключевые инсайты │
│  ...              │
├────────────────────┤
│       +           │  ← новый чат (большой плюс по центру)
├────────────────────┤
│  ⚙ Настройки      │  ← внизу
└────────────────────┘
```

- Фон: `#ffffff`
- Граница справа: `1px solid rgba(0,0,0,0.05)`
- Активный пункт: `background: #222224`, `color: white`, `padding: 6px 14px`, `border-radius: 40px`
- Неактивный: `color: rgba(101,101,102,0.8)`, hover: `rgba(9,14,23,0.8)`
- Заметки (треды): 13px, Muller Regular, обрезаются через ellipsis
- "+" внизу: крупный символ, `rgba(9,14,23,0.2)`, центрирован

### Сайдбар — свёрнутый (60px)

```
┌──────┐
│ [☆] │  ← только лого
│  +   │
│  ☀  │
│  □   │
│  ○   │
│      │
│      │
│  ⚙  │
└──────┘
```

- Только иконки, без текста
- Анимация: `transition: width 300ms cubic-bezier(0.4, 0, 0.2, 1)`
- При сворачивании основной контент расширяется

### Экран "Новый чат" (пустой)

```
                      есть мысли?

          ┌──────────────────────────────────┐
          │  Спрашивай о чём угодно          │
          │  +                          [🎤] │
          └──────────────────────────────────┘
```

- "есть мысли?" — Random Grotesque, ~36px, по центру, `rgba(9,14,23,0.8)`
- Инпут: 600px max-width, по центру
- Фон экрана: `#f9f9f9`

### Экран чата (с историей) — по референсу Perplexity

```
  сообщение пользователя справа в pill-пузыре
  
  Ответ Мысли — plain text, без пузыря, слева
  
  [action-bar под ответом: иконки]
  
  ─────────────────────────────────────────
  ┌──────────────────────────────────────┐
  │  Задайте уточняющий вопрос           │
  │  +                    Модель ∨  🎤  ↑│
  └──────────────────────────────────────┘
```

- Пузырь пользователя: `background: rgba(9,14,23,0.06)`, `border-radius: 20px`, `padding: 10px 16px`, right-aligned
- Ответ ИИ: plain text, никакого фона, `color: rgba(9,14,23,0.8)`, `line-height: 1.7`
- Кнопка отправки: круглая, `background: #222224`, белая стрелка вверх

## UX паттерны

| Паттерн | Описание |
|---------|---------|
| Стартовый экран | При входе показывается "Сегодня", не "Новый чат" |
| Новый чат | Клик "+" или "Новый чат" → пустой экран с "есть мысли?" |
| Треды в сайдбаре | Показывают ЗАМЕТКИ (сохранённые треды), не все чаты |
| Таб-переключатель | "Твои мысли" → треды; "Заметки" → отдельный список заметок |
| Сворачивание сайдбара | Кнопка □ в шапке, плавная анимация 300ms |
| Активный пункт | Pill-подсветка, при смене экрана переезжает |
| Добавить задачу | В "Сегодня" — кнопка "+" в заголовке карточки |
| Чекбокс | Клик → плавное заполнение (анимация) |

## Что НЕ реализуем пока (backend отсутствует)

- Интеграции Google / Яндекс Календарь / Notion → UI есть, кнопки неактивны с тултипом "Скоро"
- "Память модели" → кнопка "ОЧИСТИТЬ" работает (очищает localStorage)
- "Инструкции" → поле сохраняется в профиль пользователя (уже есть `settings` в БД)
