# Дизайн-система «Мысль»

Единый источник правды по визуальному стилю. Сведён из лендинга
(`public/landing/v2.css`) и приложения (`src/index.css`).

## Файлы
- **`tokens.css`** — все токены: цвет, типографика, радиусы, тени, раскладка.
  Канонические значения + пометки, где лендинг и приложение расходились.
- **`preview.html`** — визуальный showcase системы (палитра, шрифты, кнопки,
  поля, карточка задачи, категории, пузырь Мысли). Открой в браузере.

## Шрифты
- **Muller** (400/500/700) — основной UI и текст.
- **Random Grotesque** — дисплейный, строчные заголовки («настройки»).
- **Russisch Sans** (600) — акцидентный, точечно.

## Расхождения лендинг ↔ приложение (свести к канону)
| Токен | Лендинг (канон) | Приложение сейчас |
|---|---|---|
| Фон | `#f0f0f0` | `#f9f9f9` |
| Основной текст | `#1c1c1e` | `#222224` |
| Линии | `rgba(0,0,0,.08)` | `rgba(0,0,0,.05)` |

`tokens.css` использует канонические значения. Чтобы окончательно
свести версии — обновить `src/index.css` под эти числа (отдельной задачей,
это меняет внешний вид приложения, поэтому только по согласованию).

## Как синхронизировать с Claude Design
Из своего интерактивного терминала Claude Code (где ты залогинен в claude.ai):
```
cd <путь к репозиторию Mindex>
claude
/design-sync
```
`/design-sync` прочитает токены и компоненты и выгрузит систему в Claude Design.
После этого «Мысль» появится в разделе **Design systems**, и презентации/макеты
пойдут в фирменном стиле.

> Эта папка — отправная точка. Скилл `/design-sync` дополнит её карточками
> по реальным компонентам из `src/components`.
